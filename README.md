# IT Class Tests

Static site. All questions are in `tests.json`. Edit that file on GitHub (pencil icon), commit, and Vercel updates the site in about a minute. No build step.

Each class has `tests`; each test has `secs` (sections). A section has `t` (type: mcq, tf, fill, match, rearr, one, err, short), `m` (marks per question), optional `box` (hint words) or `note` (custom instruction) and `items`. Keep every test at 20 marks.

Students open `your-site.vercel.app/#class-5` for Class 5, `#class-6` for Class 6, and so on.
